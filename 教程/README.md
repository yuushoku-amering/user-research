## 开始之前：先把它装起来（两条路）

**这几份教程默认你已经能打开界面了。** 如果还没有，先看
[`../README.md`](../README.md) 开头那张「两种版本，选一个」：

| 你的情况 | 怎么做 |
|---|---|
| **电脑上没装 Python / 不想折腾** | 下**便携版**（自带 Python）→ 解压 → 双击 `start-portable.bat` |
| **已经装了 Python** | 下**源码版** → 双击 `安装依赖.bat` → 双击 `启动工作台.bat` |

装好之后浏览器会自动打开 `http://127.0.0.1:8765/`。**关掉那个黑窗口 = 停服务。**

## 先记住三件事（三份通用）

**一、它是一条流水线，从上往下走。**

```
🔒 去标识化 ——不是某一步，是「任何材料进来的第一站」
  ↓
⓪ 研究设计 ──┬─→ ① 访谈提纲 → ② 编码整理 → ②b 范畴汇总 → 主题
             └─→ ③ 问卷设计 → ④ 问卷统计 ─┐
                                          ├─→ ⑤ 数据预处理 → ⑥ 统计分析
                                          ┘
```

左边栏就是这条线（分三组：入口 / 质性线 / 量化线）。**做到哪一步就点哪一个**，
上一步的产物会自动被下一步读到。

**二、每个模块都是「填几栏 → 跑 → 看结果」三步。**

跑完的「结果」页会给你：一句话摘要、几张表、产物文件、以及**提醒**。
提醒里能点的地方尽量点一下——那是程序在告诉你它哪儿拿不准。

**三、它是助手，不是替你下结论的。**

编码、主题、变量、统计方法、要不要匿名——**这些永远是你定**。
程序只做体力活：切材料、算数字、把线索摊开。它不会因为你没填某栏就拒绝执行，
也**不会偷偷替你决定**。

---

## 现在最要紧的三句话

1. **材料进来先过 🔒**（去标识化），尤其是转写稿和名单——里面多半有真名和手机号。
2. **做完 ⓪ 再往下**。研究问题和变量一乱，后面全乱；③ 的问卷、⑥ 的统计都是从 ⓪ 继承的。
3. **每跑完一步，先看「结果」页最下面的提醒**，再去动产物文件。

## 关于界面本身（2026-09-27 之后的版本）

界面上有几处不在流程线上、但挺常用的东西：

| 在哪 | 是什么 |
|---|---|
| 顶栏最右 **⚙** | **设置**：SPSS 的 `stats.exe` 路径、模型 API（可选功能都在这儿配，不用手改 config.json） |
| ⚙ 左边那个 **🌙 / ☀️** | **深浅色切换**（第一次打开跟随系统，点一下固定成你的选择） |
| 右边栏 **📌 待确认** | 模型给的初稿里「它不确定的地方」会收进来，可以一条条填掉 |
| 结果页的 **⏸ 检查点**（黄卡） | 关键决策点它会停下来等你拍板，选「停在这里」就真的不产出文件 |
| 结果页的 **「📋 复制任务书」** | 没配模型也能用：复制走 → 贴到任意聊天窗口 → 结果贴回来（能一键填回表单） |

**详细的界面说明在 [`../使用说明.md`](../使用说明.md)**（那份比本教程更新得勤）。

## 两个小提醒

- 更新过程序、或者改了代码之后：浏览器按 **`Ctrl+Shift+R`** 强刷一次（普通刷新可能还用着旧界面）。
  改了 `core/` 或 `server.py` 要重启服务：双击 **`重启工作台.bat`**（它会先关掉旧实例）。
- **`.bat` 启动脚本建议放纯 ASCII 路径下**（别带中文）。程序本身支持中文路径，
  但启动脚本要经过 Windows 命令行，中文路径偶尔会被控制台编码搞乱。
  —— 这一条对**便携版**尤其明显：解压到 `D:\Vesper\` 这类路径最省事。
