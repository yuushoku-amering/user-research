## 先记住三件事（三份通用）

**一、它是一条流水线，按 ⓪→⑥ 从上往下走。**

```
⓪ 研究设计 ──┬─→ ① 访谈提纲 → ② 编码整理 → ②b 范畴汇总 → 主题
             └─→ ③ 问卷设计 → ④ 问卷统计 ─┐
                                          ├─→ ⑤ 数据预处理 → ⑥ 统计分析
                                          ┘
🔒 去标识化：不是某一步，是**任何材料进来的第一站**
```

左边栏就是这条线。**做到哪一步，就点哪一个**；上一步的产物会自动被下一步读到。

**二、每个模块都是「填几栏 → 跑 → 看结果」三步。**

跑完的「结果」页会给你：一句话摘要、几张表、产物文件、以及**提醒**。提醒里能点的地方尽量点一下——那是程序在告诉你它哪儿拿不准。

**三、它是助手，不是替你下结论的。**

编码、主题、变量、统计方法、要不要匿名——**这些永远是你定**。程序只做体力活：切材料、算数字、把线索摊开。它不会因为你没填某栏就拒绝执行，也**不会偷偷替你决定**。

---

## 现在最要紧的三句话

1. **材料进来先过 🔒**（去标识化），尤其是转写稿和名单——里面多半有真名和手机号。
2. **做完 ⓪ 再往下**。研究问题和变量一乱，后面全乱；③ 的问卷、⑥ 的统计都是从 ⓪ 继承的。
3. **每跑完一步，先看「结果」页最下面的提醒**，再去动产物文件。

## 两个小提醒

- 更新过程序、或者改了代码之后：浏览器按 **`Ctrl+Shift+R`** 强刷一次（普通刷新可能还用着旧界面）。
  要重启服务就用 **`重启工作台.bat`**（它会先关掉旧实例）。
- **`.bat` 建议放纯英文路径下**，中文路径有时会被控制台编码搞乱（程序本身支持中文路径，只是启动脚本这一步偶发）。
