# 教程 ① · 第一次做研究（不熟统计、没用过 SPSS）

> 你不需要会写代码，也不需要会统计。**这个工作台就是替你干这两件事的。**
> 你只需要会一件事：**判断它给你的东西对不对**。

---

## 0. 打开它

**先确认你下的是哪一版**（这个决定你要不要装东西）：

| 你下的 | 怎么打开 |
|---|---|
| **便携版**（解压出来有一个 `_python` 文件夹） | 双击 `start-portable.bat`（或者 `岚苔Vesper\启动工作台.bat`）。**不用装任何东西** |
| **源码版**（解压出来是 `server.py`、`安装依赖.bat` 这一堆） | ① 双击 `安装依赖.bat`（等你看到「装好了」）② 双击 `启动工作台.bat` |

浏览器会自动开 `http://127.0.0.1:8765/`。**关掉那个黑窗口就是停服务**（它不会在后台常驻）。

> 💡 **建议把整个文件夹解压到 `D:\Vesper\` 这种纯英文、没有空格的路径**。
> 程序支持中文路径，但启动脚本要经过 Windows 命令行，中文路径偶尔会被控制台编码搞乱。

顶栏先**新建一个项目**（起个名字，比如「大学生恋爱研究」）。工作台会给你建好几个文件夹：

```
contracts/   你的研究设计、提纲、编码表（"想清楚"的东西）
data/        原始数据（问卷导出、转写稿）——只放不改
samples/     访谈材料
output/      程序跑出来的东西（报告、表格、脱敏稿）
_history/    程序每次覆盖产物前的旧版备份（改坏了能翻回来）
```

> **为什么非要先建项目**：所有产物都落在项目里，你打包带走、换台电脑打开，东西还在。
> 而且工作台**不会把你的项目放进软件目录** —— 项目建在你选的「项目之家」那层，
> 所以换新版本的软件不会碰到你的数据。

**改过代码或者更新之后**，浏览器要按 `Ctrl+Shift+R` 强刷一次，不然可能还用着旧界面。

> **先别急着做真研究**：左下角有 `试一下_演示.bat`（在软件目录里），
> 双击它会自己造一份合成问卷、跑一遍预处理 + 统计，几秒钟把结果摊开给你看
> —— 不用建项目、不用开浏览器。先看一遍它长什么样，再拿自己的材料上手。

## 1. 🔒 去标识化 —— 材料进来第一站

**什么时候用**：拿到转写稿 / 名单 / 任何带真名手机号的材料，**先过这里**。

1. 点左边 🔒
2. 「要脱敏的文件」选中你的材料
3. 点「用 Python 跑」

跑完你会看到：
- `output/脱敏_材料名.txt` —— **跟原文一样格式**的脱敏稿（可以直接拿去用）
- `output/格式说明.md` —— 程序怎么看懂这份材料的（**看不懂就改它**）
- 一堆**提醒** —— 它拿不准的地方

**提醒怎么处理**（重要，这是这个模块的核心）：

| 提醒长什么样 | 你怎么办 |
|---|---|
| 「**一行里第 3 段**拿不准：出现过 手机、学号」 | 点选项「第 3 段是手机号」—— **说一次，整份材料都照办** |
| 「「138xxxx」可能有歧义（原文第 7 行）」 | 点「看原文第 7 行」自己看一眼，再点「这是手机号」或「是 QQ」 |
| 「这些词没被认出来：…」 | 有需要脱敏的就点选项加进去；**没有就点「🙈 这条不用再问」** |
| 「有 N 条指令看不懂，被跳过了」 | 去「自定义替换」框看**每行后面的 ✓/✗**，✗ 的改掉或删掉 |

**两个名词，记住就行**：
- **直接标识符**（真名、手机、身份证、学号、微信）→ 程序**直接换掉**
- **准标识符**（年龄、学院、城市）→ 只**提示**，换不换你定（因为"25 岁"要不要粗化成年龄段，跟你的研究目的有关）

⚠️ **「编号对照表」本身是敏感文件**（它写着谁换成了什么），单独保管或按伦理要求销毁，**别和脱敏稿放一起**。

## 2. ⓪ 研究设计 & 主题澄清 —— 地基

**这是最重要的一步。** 后面所有东西都从这里继承。

要填的其实就四栏：
- **背景 / 目的**：你为什么做这个研究？想让谁知道什么？
- **研究问题**：2~4 个，用问句写
- **关键变量与操作化定义**：一张表，每条变量写四样 ——
  `变量名 · 角色（自变量/因变量/中介/调节/控制） · 测量层次（定类/定序/定距/定比） · 怎么测`
- **研究对象**：你要访谁 / 问谁

> 「操作化定义」是什么意思？就是**把一句虚的话变成能问出来的东西**。
> 比如"恋爱压力"→ 你说清是"每月为恋爱花的钱占生活费比例"，程序就能给你出一道问卷题。
> **你不写，程序就只能瞎猜**（它会给一份空壳问卷，并明确告诉你这是空壳）。

**测量层次**别被名字吓到，就四种：
- **定类**：只是类别，不能比大小（性别、专业）
- **定序**：能排序，但差距不均等（年级、满意度五级）
- **定距 / 定比**：是数字，能加减（年龄、每月花销、题项均分）

跑完去 `contracts/research_brief.md` 看一眼，填错了直接改这份文件，再跑一次就按你改的来。

---

## 3. ① 访谈提纲设计 → ② 编码整理 → ②b 范畴汇总

这三步是**质性线**：访完 → 拆开 → 找主题。

### ① 提纲
从 ⓪ 的研究问题生成提纲。**它给的是草稿**，你删掉不想要的、加上你想问的。

### ② 编码整理
1. 把转写稿（`.txt` / `.md` / `.srt`）放进 `samples/`
2. 选中它，「怎么拆发言单元」选**按说话人**（转写稿是「小明：…」格式时）
3. 跑

产出 `output/编码工作表.csv`，用 Excel 打开就是一张能填的表：

| # | 说话人 | 原文 | 关键词 | **开放编码** | **范畴** | **主题** | 可作引语 |
|---|---|---|---|---|---|---|---|
| 1 | 小明 | 大二在一起的… | 一起、时间 | ←你填 | ←你填 | ←你填 | ★ |

**后三列故意留白 —— 编码是你的活，程序不替你做。** 它只把材料切整齐、把高频词和好句子挑出来。

> 打开方式：Excel 里「另存为」时选 **UTF-8 CSV**，不然中文会变乱码。

### ②b 范畴汇总
填完编码表，跑这一步。它把同一范畴下的发言归到一起，给你：
- `编码汇总.md` —— 每个范畴配它的原话（写论文/报告直接抄）
- `编码_主题矩阵.csv` —— 主题 × 范畴的矩阵，看哪个主题材料最多
- **覆盖度提醒** —— 只有 1~2 个人提到的"主题"，它会说这还不足以当主题

## 4. ③ 问卷设计 → ④ 问卷统计 → ⑤ 预处理 → ⑥ 统计分析

**你没做过问卷也没关系，按顺序走一遍就行。**

### ③ 问卷设计
从 ⓪ 的变量表生成题目。产出 `output/问卷_题项表.csv`。
**每一题都会告诉你"为什么这样设计"**（哪一条变量决定它）。有不对的，回 ⓪ 改变量、重跑。

### ④ 问卷统计（拿到回收数据之后）
把问卷导出的 `.xlsx` / `.csv` 丢进 `data/`，选它，跑。会给你：
- 每道题的分布（单选/多选的百分比、量表题的均值和标准差）
- 开放题的高频词
- 你指定的交叉表

### ⑤ 数据预处理
这一步是**替你把数据洗干净**：
- 缺失值怎么处理（删行 / 补均值 / 保留）
- **反向题**要不要翻转（"我从不焦虑"这种题，分数方向是反的）
- **多题合成一个维度**（3 道题测"恋爱压力"，合成为一个分数）
- 异常值标出来（不删，只标）

产出 `output/clean_data.csv`。

### ⑥ 统计分析
**这一步不要求你会 SPSS。** 你只要说清三件事：
- **你的研究问题是什么**（比如"谈恋爱的人和不谈的人，每月花销有没有差别"）
- **因变量**是哪个（每月花销）
- **分组 / 自变量**是哪些（恋爱状态）

程序会：选好该用的检验（**并告诉你为什么选它**）、算出来、把结果写成人话，
还会生成一份 **SPSS 语法文件**（`.sps`）。你装了 SPSS 的话，它**会自己跑一遍并把 SPSS 的输出带回来**
——具体怎么跑见下面《SPSS 到底怎么跑》。

> 每次输出都会带一句「**这个结论能说到什么程度**」——
> 比如"只能说两组有差别，不能说谁导致了谁"。**这句话要认真看**，写报告时照它写，别说过头。

## 5. 常见卡住的地方

| 现象 | 原因 / 怎么办 |
|---|---|
| 双击 `.bat` 一闪就没了 | 看窗口里那行字。多半是**没找到 Python**（源码版）→ 双击 `安装依赖.bat` 会告诉你怎么办；或者干脆换**便携版** |
| 提示「端口被占用」 | 你可能开了两个工作台。关掉多余的黑窗口，或用 `重启工作台.bat` |
| 点选项没反应 / 绿字不见了 | 先 `Ctrl+Shift+R` 强刷。还不行就看「自定义替换」框每行后面的 ✓/✗ |
| 中文变乱码 | Excel 打开 CSV 要按 UTF-8；程序读文件会自己试三种编码 |
| 说「没找到 contracts/xxx.md」 | 前一步还没跑。左边栏从上往下补 |
| 问卷出了「0 道题的空壳」 | ⓪ 的变量表空着。回去填 |
| 导入数据时报「缺 pyreadstat」 | 你要读的是 SPSS 的 `.sav`。两条路：在 SPSS 里「另存为 CSV」再导入，或者装它（`安装依赖.bat --optional`）。**csv / xlsx 不受影响** |
| SPSS 那边没动静 | 见下面《SPSS 到底怎么跑》 |

## 5b. SPSS 到底怎么跑（2026-09 更新过，和早先的说明不一样）

**先说你完全可以不管它**：⑥ 的数字是**本机 Python 算的**，SPSS 只是用来"复核一遍"。
不装 SPSS、不跑它，主要结果一样有。

**如果你装了 SPSS**，⑥ 的结果页里会多出这些东西，程序会**按顺序自己试**：

1. **先试安静跑**（推荐）：它生成一个 SPSS 作业文件，用 `stats.exe -production` 跑一遍 ——
   **SPSS 自己跑完、自己退出，不用你碰界面**。跑完它的输出（三线表那些）会**直接嵌在结果页里**给你看。
2. **安静跑不通就退回界面**：它会**替你打开 SPSS** 并载入语法，界面上提示你
   「按 `Ctrl+A` 全选 → `Ctrl+R` 运行」。跑完工作台会自动把导出的结果收回来。
3. **没配 SPSS 路径**：它连试都不试，只生成 `.sps` 语法文件，你自己拿去跑。
   路径在顶栏 **⚙ 设置** 里填（或者用那里的「🔍 自动找」）。

> ⚠ 所以**旧版教程里那句「它不会替你启动 SPSS」已经不成立了** ——
> 尤其是第 2 种情况，它会真的把 SPSS 打开。如果你不希望它开界面，
> 就别在设置里填 SPSS 路径（那样它只生成语法）。

## 6. 一句话总结整个流程

> **⓪ 想清楚 → ① 问什么 → ② 把话拆开 → ②b 归成主题 → ③ 变成问卷 → ④ 收数据 → ⑤ 洗干净 → ⑥ 算出结论。**
> 材料进来先过 🔒。每一步都先看提醒，再动文件。
