# 教程 ② · 会社调、懂 SPSS，想要个提效骨架

> 你不需要学新方法。这份只讲：**它替你干哪些体力活、哪些绝不替你干、卡点在哪儿。**

---

## 一、它是什么（一句话）

一条**契约驱动**的社调流水线：⓪ 的研究设计写进 `contracts/`，后面每一步都**从契约继承**。
好处是「改了研究问题，后面的设计跟着对得上」；代价是 **⓪ 写不清楚，后面全是空壳**。

工程上就三层：`contracts`（你想清楚的东西） / `output`（程序算出来的） / `data`、`samples`（原始材料，只读不改）。

---

## 二、它**不**替你做什么（先看这个，省得白试）

| 你以为它能做 | 实际 |
|---|---|
| 自动编码访谈 | **不做**。只把材料切成发言单元、给高频线索和引语候选，后三列留白 |
| 自动定主题 | **不做**。②b 只做汇总和覆盖度提示 |
| 替你选统计方法 | 它**会推荐并说明理由**，但你可以覆盖；不覆盖时它的默认是保守的 |
| 替你决定要不要匿名化 | **不做**。准标识符只提示不替换（"25 岁"粗不粗化是研究决策） |
| 拦住你 | **不拦**。规则不合你意就照你的走，它不会因此拒绝执行 |

**一条贯穿设计的规矩**：拿不准的**必须问你**，绝不自作主张；每个判断都能回退。

---

## 三、模块流程与卡点

```
🔒 去标识化（任何材料的第一站，横切）
⓪ 研究设计 → ① 提纲 → ② 编码整理 → ②b 范畴汇总
            → ③ 问卷设计 → ④ 问卷统计 → ⑤ 预处理 → ⑥ 统计分析
```

### 🔒 去标识化 —— 这块比一般的"查找替换"认真

- **认得出**：姓名（含上下文里的昵称、同形地名）、手机（**含带分隔符/全角**）、身份证、邮箱、QQ/微信（含标签式）、学号工号、银行卡、座机、车牌
- **准标识符**只提示：年龄、精确单位、收入、具体日期、门牌、行政区、可识别特征（"我们部门就我一个女生"）
- **默认不生成对照表**；勾了才生成，且提醒你它本身敏感
- 三种产出：脱敏稿（**同格式**）、`格式说明.md`（程序怎么理解这份材料）、`去标识化报告.md`

**两个设计选择值得知道**：

1. **格式先识别、拿不准再问你**。它会看懂"记事簿式 / 一行一条 / 标签式"，把**行内第几段**是什么列出来让你确认。你确认一次（`!第3段是手机`），**整份材料照办**——不用逐行填。
2. **编号两种模式**（表单里选）：
   - 按出现顺序 → `[姓名1] [手机1]`（默认，连续好读）
   - **按序号** → `[姓名R07]`（你材料里本来就有编号列时用，脱敏稿能直接对回原始记录）；没编号列就用**原文行号** `[姓名#5]`
   ⚠ 按序号会把"第几条"的线索留在稿子里，匿名强度略降——自己权衡。

**它明确拒绝 OCR / 识图**：图片、截屏不给做（理由是视觉模型要上传云端，和"本地脱敏"的目的冲突）。图你自己用手机自带提取文字。

### ⓪ 研究设计 —— 契约的源头

产量最大的一栏是**变量与操作化定义**（`变量名 · 角色 · 测量层次 · 怎么测`）。

- 「测量层次」直接决定 ③ 出什么题、⑥ 用什么检验。**填错，后面全歪**，所以 ③⑥ 都会把它回显给你。
- 「怎么测」写具体（"5 级 Likert" / "定比，元" / "多选，可多选"），③ 就出对应的题型；不写就兜底成 NPS 或数字填空。

### ① 访谈提纲 / ② 编码整理 / ②b 汇总

- ① 从研究问题 + 变量生成提纲草稿（含追问句式、访谈者注意事项）
- ② 拆发言单元（按说话人 / 段落 / 句子），挑关键词、候选主题线索、**引语候选**（`★`）
  - 会认转写稿头部的元信息（访谈时间/地点/受访者）不当发言
  - 可丢纯附和（「嗯」「对」）、可设最短字数
- ②b 汇总范畴 → 主题，出**主题×范畴矩阵**和**覆盖度提醒**（一两个人提到的，先别当主题）

### ③ 问卷设计

- 从变量表出题，每题标注**由哪条操作化定义决定**（可核验：改 ⓪ 就会跟着变）
- 题型按测量层次走：定类→单选、定序→李克特、定比→数字/填空、多选→多选
- 量表题会自动做**选项锚点**（有现成的就搬现成的，没有才吐"互斥选项+其他"）
- 产出 `survey_design.md` + `问卷_题项表.csv`（可直接给问卷星/腾讯问卷排版）

### ④ 问卷统计 / ⑤ 预处理 / ⑥ 统计分析

- ④ 描述统计：单选/多选百分比、量表均值标准差、开放题词频（**不做推断统计**，那是 ⑥）
- ⑤ 预处理：缺失（不动只报告 / 整行删 / **只删真漏答（跳题的人留着）** / 均值·中位数·众数填补 /
  **多重插补 MICE**）、**反向题翻转**、**多题合成分数（α 会算给你）**、异常值标记（z 或 IQR，**只标不删**）
  - ⚠ 多重插补那条最值得用：均值填补会**压小方差** → 标准误偏小 → p 值偏乐观。
    程序会给你一张「完整个案 / 均值填补 / 多重插补」并排对照表，把代价摆出来
- ⑥ 统计：你说研究问题 + 因变量 + 分组/自变量 → 它选检验、算、写成人话
  - 相关系数按变量类型走（定序×定序默认 Spearman，结多用 Kendall tau-b；定类×定类给 GK tau + 卡方/Cramér's V）
  - 连续×连续**三个系数一起报**（Pearson / Spearman / Kendall，各自带 CI）——
    差得远就说明"关系是单调的但不线性，或被极端值拽歪了"，只报一个等于藏信息
  - 参数/非参数、单尾/双尾、df 与 Levene 行的读法都会说明
  - 除了组间差异/相关/回归，还有：**配对 t 与 Wilcoxon 符号秩**（被试内）、**偏相关**、
    **逻辑回归**（因变量只有两类时自动走它）、**中介/调节**（bootstrap CI + Johnson-Neyman）、
    **因子分析/效度**（KMO + Bartlett + varimax + 平行分析）、**加权分析**
  - **每个统计量都带 CI 和效应量**，不只是一个 p 值
  - **多重比较总账**：跨多次分析累计登记检验，提醒你 `1-0.95^n` 的假阳性风险
    （**只登记、不自动改你的结论**）
  - **结论敏感度**：按 Cook's D 找出"影响特别大的几个个体"，出一张「含/不含它们」的对照表。
    ⚠ 它**不删数据、不改主结果**，只是让你知道结论有多依赖那几行
  - **`.sps` 每次都生成**；装了 SPSS 的话它会**自己跑一遍并把输出嵌进结果页**（见下）

## 四、值得知道的几个"边界"

1. **不静默**。解析不出来、字段对不上、缺依赖——都会变成提醒，不会假装成功。
2. **版本可回退**。产物直接改也行，旧版自动进 `_history/`；能对比两版差异、能给版本写说明。
3. **提醒能关**。看过的提醒点「🙈 这条不用再问」，记在**项目里**（不是浏览器），跟着项目走。
4. **换个项目不用重训**。领域判定（访谈技巧、抽样、统计口径）在 `knowledge/*.md`，是**数据不是代码**；材料怎么切由程序每次现场识别，你只需确认一次。
5. **`knowledge/` 你可以改**。每条判定都写着 `kind`（行业惯例 / 某家观点 / 经验法则 / 工作台自身）和出处——不同意就改，下次跑按你改的来。

## 五、最短上手路径

```
新建项目 → 🔒 脱敏转写稿 → ⓪ 写研究问题 + 变量表
        → ① 出提纲 → 访 → ② 拆 → 填编码 → ②b 归主题
        → ③ 出问卷 → 收数据 → ④ 描述 → ⑤ 预处理 → ⑥ 检验（拿 .sps 去 SPSS 复核）
```
