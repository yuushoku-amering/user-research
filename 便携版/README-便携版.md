# 岚苔 Vesper · 用户研究工作台 —— 便携版

**这个包里已经带了 Python，你什么都不用装。** 解压 → 双击 → 用浏览器做研究。

---

## 一、怎么用（三步）

1. **解压**
   把这个 zip **完整解压**到一个文件夹。
   ⚠ 放哪都行，但**路径里别带中文和空格**会更省事，比如 `D:\Vesper\`。
   ⚠ **别在 zip 里面直接双击** —— Windows 的"压缩文件夹预览"里跑不起来。
   ⚠ 解压后 `_python` 和 `岚苔Vesper` 两个文件夹要**待在一起**，别只拷一个走。

2. **想看它能干什么 → 双击 `岚苔Vesper\试一下_演示.bat`**
   不用开浏览器、不用建项目，它会自己造一份合成问卷，
   跑一遍「预处理 → 统计分析 → 结论」，几秒钟出结果。
   看完可以直接把 `岚苔Vesper\_jobs\demo_project` 删掉。

3. **真要用 → 双击 `start-portable.bat`**
   浏览器会自动打开 `http://127.0.0.1:8765`。
   第一次会让你选一个目录当「项目之家」（你的研究项目都建在那下面）。
   **关掉那个黑色窗口 = 停止服务。**

> 也可以双击 `岚苔Vesper\启动工作台.bat`，效果一样。
> 根目录那个 `start-portable.bat` 只是省得你往里点一层。

## 二、两个可选功能（不配也能用全部功能）

打开界面右上角的 **⚙ 设置**：

### SPSS 复核 —— 需要你电脑上装了 SPSS

装了 SPSS，才能「顺便用 SPSS 跑一遍同一件事」、把它的输出带回来对照。
设置页里点 **🔍 自动找**（在常见安装位置里扫一遍），或 **📁 浏览…** 手动选 `stats.exe`。

**没装 SPSS 完全不影响其它功能** —— 工作台照样生成 `.sps` 语法文件，你可以拿去别的机器跑。

### 模型建议 —— 需要你自己有一个 API Key

模型只做「给初稿」（提纲初稿、把大白话拆成结构化意图），**不参与任何算术**。
两条路，选一条：

- **自带 API**：在设置页填「接口地址 / 密钥 / 型号」，点「🔌 测试连接」。
  走的是标准 OpenAI 兼容接口，所以 **DeepSeek、硅基流动、智谱、本地 Ollama** 都能填。
- **什么都不配**：所有组块都能跑通。缺模型时界面上有「📋 复制任务书」，
  贴到任意聊天窗口（网页版也行）、把结果贴回来一样能用。

> **密钥只写进你这台机器的 `岚苔Vesper\config.json`**，不会上传到任何地方，
> 界面上也只显示"已设置"和脱敏形态，不回显原文。

## 三、包里是什么

```
岚苔Vesper-便携版\
├── start-portable.bat        ← 双击这个开始（推荐）
├── _python\                  ← 自带的 Python 3.10 + numpy/pandas/scipy/matplotlib
│                                （不用装、不写注册表、不动你系统里的任何 Python）
└── 岚苔Vesper\               ← 工作台本体（全是明文 .py/.js/.css/.html，随时能删）
    ├── 启动工作台.bat           ← 也可以用这个启动
    ├── 试一下_演示.bat          ← 不开浏览器看它能干什么
    ├── README.md              ← 项目说明
    ├── 使用说明.md             ← 完整功能说明
    └── 教程\                  ← 三份教程：新手 / 有经验 / 企业用研
```

**服务只在 `127.0.0.1` 上听**（只有本机能访问）。开机不自启、不写注册表、
不建计划任务、不留后台进程。删掉整个文件夹 = 彻底卸载干净。

研究项目会建在**你选的「项目之家」**里，跟这个软件文件夹分开，
所以以后换新版本只要把 `岚苔Vesper\` 换掉、项目原封不动。

## 四、可能遇到的问题

| 现象 | 怎么办 |
|---|---|
| 双击没反应 / 一闪而过 | 右键 →「以管理员身份运行」试试；或先看窗口里打印的那句话 |
| 提示 `_python\python.exe is missing` | zip 没解压完整，或你把 `_python` 挪走了 —— 重新解压 |
| 浏览器没自动打开 | 自己打开浏览器，地址栏输 `127.0.0.1:8765` |
| 提示端口被占用 | 关掉以前开着的那个黑窗口（可能开了两个） |
| 「导入」显示缺包 | 是 `pyreadstat`（读 SPSS 的 `.sav`）没装。**不影响 csv/xlsx**； 真要读 `.sav`，可以在 SPSS 里先导出成 csv |
| 杀软报毒 / 拦了 | 便携版里带的是 python.org 的官方 Python，被误报是常见事；把整个文件夹加进白名单 |
| 想装额外的包 | 包里带了 pip：`_python\python.exe -m pip install 包名` |

**担心电脑上已经有别的 Python？放心** —— 这个包用的是自己那份，
不会碰、也不会被系统里那份影响。想验证：启动后看界面顶栏「引擎 ✅」的悬停提示，
路径指向本包里的 `_python` 就对了。

## 五、这个包是怎么来的（给想自己打包的人）

1. 复制一份官方 CPython（本机上是 Python 3.10.10）
2. 把工作台源码放进去（排除 `_jobs/ libs/ dsh-home/ .git/ config.json`）
3. 写一份 `config.json`，其中 `python` 指向 `..\_python\python.exe`
4. 删掉用不到的包（省 131MB：`pymupdf / statsmodels / pdfminer / lxml / cryptography …`）
   ⚠ **别删 PIL** —— `matplotlib.colors` 依赖它，删了图就画不出来（踩过）
5. 删 `Lib\test`（CPython 自带测试）、`Lib\idlelib`、所有 `__pycache__`

**打包后必须验的三件事**（少一件都可能发出一个跑不起来的包）：

- 换一个路径之后 `python.exe` 还能跑（`sys.prefix` 要跟着走）
- `engine_python()` 解析出来的是**内置那只**，不是用户机器上碰巧装的那只
- `试一下_演示.bat` 能完整跑完并出图
