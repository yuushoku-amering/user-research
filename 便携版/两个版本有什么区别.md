# 两个版本有什么区别？我该下哪个？

这个项目同时发布两种形态。**先看这张表，30 秒决定。**

| | **便携版**（推荐给大多数人） | **源码版**（给有 Python 的人 / 想改代码的人） |
|---|---|---|
| 下载的是什么 | 一个约 120 MB 的 zip | 仓库源码（约 3 MB） |
| **要装 Python 吗** | **不用** —— 包里自带 Python 3.10 和全部依赖 | **要** —— 需要 Python 3.8+，还要 `pip install pandas scipy matplotlib numpy openpyxl` |
| 解压后能直接用吗 | 能。双击 `start-portable.bat` 就起来了 | 要先装依赖、复制 `config.json`，再双击 `启动工作台.bat` |
| 第一次能用上要多久 | 解压（1~2 分钟）+ 双击 | 装 Python（10~30 分钟，视网速）+ 装依赖 + 试错 |
| 占用磁盘 | 解压后约 350 MB | 约 3 MB + 你自己那份 Python |
| 更新新版本 | 重新下一整个 zip，**把项目文件夹挪过去** | `git pull` 一条命令（几秒钟） |
| 会不会动你的系统 | 不会。不写注册表、不改 PATH、不装服务，**删掉文件夹 = 卸载干净** | 需要你自己先装好 Python（那是装在你系统里的） |
| 适合谁 | 研究者、同学、导师、任何"电脑上没 Python / 不想折腾"的人 | 开发者、要读改代码的人、要接自己数据集做二次开发的人 |
| 想装额外的包 | 包里带了 pip：`_python\python.exe -m pip install 包名` | 用你自己的 Python 装 |
| 体积为什么差这么多 | 里面的 Python + numpy/pandas/scipy/matplotlib 加起来就 300 多 MB（**科学计算库本来就大**） | 源码只有几 MB，重的东西在你自己的环境里 |

## 一句话结论

- **你只想用它做研究** → 下**便携版**。
- **你电脑上已经有 Python，而且不介意敲两条命令** → 源码版更轻、更新更方便。
- **你想改代码 / 看懂它怎么算的** → 源码版（便携版里也有全部源码，一样能读，只是更新麻烦）。

## 两个版本**功能完全一样**

便携版不是"精简功能版"。它和源码版跑的是**同一份代码**（同一个 `server.py`、同一套 `blocks/`），
差别只在于** Python 从哪来**：

```
便携版：  岚苔Vesper-便携版\_python\python.exe   ← 包里自带
源码版：  用你系统里装的 python.exe              ← 你自己装
```

九个组块、检查点、SPSS 复核、模型建议、深色模式、设置页 —— 两边一模一样。

## 便携版有一点要注意

**它自带的 Python 是"这一份"的**，跟你电脑上装的 Python **互不影响、互不干扰**：

- 你系统里的 Python 是 3.12 还是根本没装，都不影响便携版
- 便携版也不会往你的系统 Python 里装任何东西
- 想验证：启动后把鼠标停在顶栏「引擎 ✅」上，路径指向**包里的 `_python`** 就对了

**唯一少的东西**：便携版**没有 `pyreadstat`**（读 SPSS 的 `.sav` 文件用的）。
它不影响任何其它功能 —— 你平时用 csv / xlsx 完全没问题。
真要读 `.sav`，两条路：① 在 SPSS 里先导出成 csv；② 用包里自带的 pip 自己装：

```
_python\python.exe -m pip install pyreadstat
```
