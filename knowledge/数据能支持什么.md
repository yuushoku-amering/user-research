# 数据能支持什么 · 判定规则

**这份文件回答一个问题：你想知道的事，你手上的数据能不能回答？**

它被两处用到：

- **⑥ 统计分析**：你写了大白话意图之后，先按这里的规则过一遍，
  命中哪条就**在推荐方法之前**告诉你——因为有些问题不是"换个方法就能答"，是数据本身答不了
- **② 编码汇总 / ③ 问卷设计**（将来）：同一个道理，别让它只发生在统计那一步

## 哪些是"改了就生效"，哪些只是"读得懂"

| 类别 | 能不能改 | 说明 |
|---|---|---|
| **条目** | ✅ 可以自己加 | 按下面的字段结构加一条就行（**字段不能少**，少了程序读不出来） |
| **触发词 / 要求 / 降级路径 / 为什么** | ✅ 改了立刻生效 | 都在下面那个 ```json 块里 |

**字段结构（每条必须有这五项，缺一个程序会跳过它并报出来）**：

| 字段 | 意思 |
|---|---|
| `id` | 唯一的短名字（英文/拼音都行），报告里会引用它 |
| `触发词` | 你的问题里出现这些词，就可能命中这条 |
| `要求` | **要回答这个问题，数据必须满足什么** |
| `现在给你什么` | 数据不满足时，我还能给你什么（**必须有东西给**） |
| `降级路径` | 想要真正的答案，得补什么数据 |
| `为什么` | 一句话原理——给人看的，答辩时能照着说 |

## 一、常见条目

### 横截面 × 因果

- **触发词**：导致、造成、使得、影响、因为…所以、**更容易**、**会让人**
- **要求**：有时间先后（因在前、果在后），最好是两次测量
- **现在给你什么**：相关 / 组间差异，并写明「只能说明这两件事**同时**发生」
- **降级路径**：补一次追踪测量（前后测）；或做实验/准实验设计；或用访谈补"机制"这一层
- **为什么**：横截面数据是**同一个时间点**上拍的照，"谁先谁后"这件事没有信息

> ⚠ 这条最常被忽略的写法是"**花钱多的同学更容易分手**"——
> "更容易"已经预设了时间先后，可你只有一次测量。

### 一次测量 × 变化

- **触发词**：越来越、变得、变化、提升、下降、趋势（**关于随时间变化的那种**）
- **要求**：同一批人至少测两次
- **现在给你什么**：只能描述**当前**的状态，或按年龄/年级做**横断比较**（那不是"变化"）
- **降级路径**：追踪设计（同一批人隔一段时间再测一次）
- **为什么**：一次测量分不出"本来就这样"和"后来变了"

### 自评 × 客观行为

- **触发词**：实际、真实、客观、到底、真正的
- **要求**：客观记录（日志、消费流水、后台数据）或他人评定
- **现在给你什么**：自评结果，并写明「这是**自我报告**」
- **降级路径**：补客观数据（比如消费流水）；或用多来源三角验证
- **为什么**：自评受记忆、印象管理、社会期许影响，跟客观行为**只是相关**

### 区间档位 × 边际效应

- **触发词**：每多、每增加、每提高、斜率、一元对应多少
- **要求**：变量是**真连续的**（有小数或取值很多），不是分档选项
- **现在给你什么**：档位之间的**均值差 / 中位数差**（"高档比低档多多少"）
- **降级路径**：把题改成数值填空（但会牺牲作答体验）；或至少用**等宽档位**再取中点
- **为什么**：区间之间的"减法"是我们自己填的中点假设出来的，不是数据里的信息

### 多选题 × 单一分类

- **触发词**：主要是、最主要、首选、哪一个更重要
- **要求**：单选题，或数据里指明了"主选"是哪一个
- **现在给你什么**：每个选项的**选择率**（多少人选了它），或拆成多个"选/没选"分别分析
- **降级路径**：在题里加"请选出最主要的一项"；或在数据里标出主选规则
- **为什么**：多选题没有"唯一个值"，硬取一个（比如按选项顺序取第一个）会**系统性偏向排在前面的选项**

### 小样本格子 × 卡方

- **触发词**：（这条由数据触发，不看措辞）交叉表、卡方、关联
- **要求**：期望频数 <5 的格子不超过 20%
- **现在给你什么**：卡方结果，但**明确标出**有多少格期望频数 <5
- **降级路径**：把小类合并（比如"其他"和"不愿透露"并成一类）
- **为什么**：格子太稀时卡方的分布近似不成立，p 值不可信
