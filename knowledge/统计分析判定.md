# 统计分析判定规则

⑤ 统计分析这一步的判定。以前这些**散在 `engine.py` 和 `kit.py` 里**，改一条要去翻代码；
现在放在这儿：看得见、改得动、能追问出处。

## 哪些是"改了就生效"，哪些只是"读得懂"

**必须说清楚**，不然就是骗人：

| 类别 | 能不能改 | 说明 |
|---|---|---|
| **数值判定** | ✅ 改了立刻生效 | 下面的 ```json 块里的数字（VIF 阈值、Cook's D、DW 区间、有序量表判据…）由程序读 |
| **方法论流程** | 📖 只能读 | 「方法怎么选、前提不满足怎么办」的流程仍然在 `engine.py` 里。<br>不过它**每一步的判断依据都会写进报告**（「分析计划（决策树）」那张表），研究员看得见、也能在检查点当场拦下来改 |

也就是说：**数字你能改，流程你能看能拦，但不能靠改这个文件改流程。**
这是刻意的——流程改错会算出错的数，数字改错只会影响判断宽严。

## 一、显著性水平

默认 α = 0.05。**研究员在 ⑤ 的表单里填的值优先**，这里是兜底。

## 二、有序量表怎么认

「1~5 / 1~7 这种有序量表题」在回归里**按分数用**，不能当分类拆哑变量。

**为什么**：拆成哑变量等于丢掉了顺序信息（5 比 4 高一点这件事没了），
还会白吃好几个自由度、把 VIF 抬上去——报告里就全是「共线性偏高」的警告，
而真正的问题可能只是这里认错了。

判据（四条全满足才算有序量表）：
- 有效样本 ≥ 10
- 全是整数
- 不同取值 3~7 个
- 取值连续（从最小到最大不缺号，比如 1,2,3,4,5）

## 三、回归诊断的红线

| 指标 | 红线 | 意味着 |
|---|---|---|
| VIF | > 10 严重、> 5 需注意 | 系数不稳，**别拿它排重要性** |
| Cook's D | > 4/n 值得看、> 1 是强影响点 | 删掉这一个样本，结论可能就翻了 |
| Durbin-Watson | 1.5~2.5 之外 | 残差可能自相关（时间/空间顺序的数据要当心） |
| 残差正态性 | Shapiro-Wilk p ≤ α | 偏态 → p 值可能偏乐观，别只看星号 |

**注意 VIF 有一条例外**：分类变量拆成哑变量之后，同一组的各档之间天然相关，
VIF 会偏高——这时候别急着删变量。

## 四、方法怎么选（流程，只读）

**这张表就是报告里那张「分析计划（决策树）」的内容来源**，每一步的理由都会写进报告。

### 组间差异（几组人的某个指标不一样吗）

| 判断 | 选什么 |
|---|---|
| 2 组 + 正态 + 方差齐 | 独立样本 t 检验 |
| 2 组 + 正态 + 方差不齐 | Welch t 检验 |
| 3 组及以上 + 正态 + 方差齐 | 单因素方差分析 + Tukey 事后 |
| 3 组及以上 + 正态 + 方差不齐 | 方差分析（Welch 校正，谨慎解释） |
| 任一组不正态 | Mann-Whitney U（2 组）／ Kruskal-Wallis（3 组及以上） |

**前提不满足时**：按表单里「前提不满足时怎么办」的设定走——
换非参数（推荐）／坚持参数方法但标注风险／停下来只报前提。
**默认推荐换非参数**：它比的是秩次、中位数，不依赖正态假设，代价是检验力略低。

### 关系与预测

| 判断 | 选什么 |
|---|---|
| 两个连续变量 | Pearson 相关（不正态则 Spearman） |
| 一个连续因变量 + 多个自变量 | 多元线性回归 + 诊断 |
| 分类自变量 | 拆哑变量（去第一类）；**有序量表按分数用** |

### 分类关联

两个分类变量 → 交叉表 + 卡方。**注意**：期望频数 <5 的格子超过 20% 时，
卡方不稳，报告里要标出来。

### 配对 / 前后测（2026-09-26 加）

**同一批人测了两次**（干预前 vs 干预后）—— 这和「组间差异」是两回事，别选错。

| 判断 | 选什么 |
|---|---|
| 差值的正态性满足 | 配对样本 t 检验 |
| 差值不正态 | Wilcoxon 符号秩检验 |
| 只有一列 + 一个参照值 | 单样本 t 检验 |

**最关键的一条：前提检验落在「差值」上，不是原始两列。**

> 前后测两列各自都可能偏得厉害（比如指数分布），但只要**差值**近似正态，
> 配对 t 就完全没问题。只看「两列各自正态吗」就换非参数，
> 会**白丢配对带来的检验力**（把本来显著的差别做成不显著）——
> 这是配对设计里最常见的一处误用。

**方向固定为「第二列 − 第一列」**（一般是「后测 − 前测」）。
方向反了：均值差会变号、**但双尾 p 不变** —— 所以方向必须靠报告的表述固定，
不能指望数字自证。

**打平（前后完全一样）要报出来**：它们不参与秩和。打平比例高时（≈20% 以上），
符号秩的检验力会明显下降，这时**不显著别直接读成「没变化」**，
可以再看符号检验（只看方向）或配对 t 作对照。

### 偏相关（2026-09-26 加）

填了「控制变量」就做偏相关：**把控制变量按住不动，再看 x 与 y 还剩多少关系**。

做法：x 和 y 各自对控制变量回归、取残差，再算两个残差的相关
（和 SPSS 的 `PARTIAL CORR` 同一个定义）。

**什么时候必须用**：两个变量看起来有关，但可能是**第三个变量同时推高了两边**。
典型例子：身高和阅读能力正相关，扣掉年龄就没剩多少。
不报这个数，研究员会拿那个「看起来有关」的相关系数去写「两者高度相关」。

自由度 = **n − 2 − k**（k = 控制变量个数），比普通相关少，CI 要用这个 df 折算。

### 中介 / 调节（2026-09-26 加）

**这两个是两个不同的问题，最容易被混为一谈：**

| | 问的是 | 做法 |
|---|---|---|
| **调节** | X 的作用**随 W 变化**（"在什么条件下更强"） | 回归里加**交互项 X×W** |
| **中介** | X **通过 M** 影响 Y（"经由什么"） | 拆 a 路径（X→M）和 b 路径（M→Y），间接效应 = a×b |

填了「中介变量」就做中介、填了「调节变量」就做调节；两个都填就两个都做（分开报）。

**中介的三条硬规矩**：

1. **必须用 bootstrap 取区间，不用 Sobel 检验** —— 间接效应 a×b 的抽样分布
   不是正态的（两个随机变量相乘），Sobel 假设正态 → p 值和区间都偏。
   本工作台默认 **5000 次、百分位法、固定种子**（每次跑出同一个区间，可复现）。
2. **它只说明"统计上存在间接路径"，不是因果证明**。
   "X 真的导致 Y" 要靠**时间先后或实验设计**，不是靠这个检验。
   横截面数据做中介，报告里必须写明这一点。
3. **完全中介 / 部分中介**看**直接效应 c′ 还显不显著**：
   c′ 不显著 = 完全中介；c′ 仍显著 = 部分中介。

**调节的两条硬规矩**：

1. **交互项要先对中**（centering）—— 不对中的话 X 的系数变成
   "W=0 时 X 的作用"，而 W=0 常常没有实际意义（比如"生活费=0"）。
   对中之后 X 的系数是"在 W 平均水平上 X 的作用"，可解释，
   而且交互项与主效应的共线性小很多。
2. **只有交互项显著才叫有调节** —— X 主效应显著**不等于**有调节。
   报告里要给出**简单斜率**（W 取低/中/高时 X 的作用）和
   **Johnson-Neyman 区间**（W 在哪个范围内 X 的作用显著）——
   后者比"只报 ±1SD 两个点"信息量大得多，但转折点可能落在数据实际范围之外，要说明。

### 因子分析 / 效度（2026-09-26 加，在 ④ 问卷统计里）

答的是「**这 10 道题是不是在测 2 个东西**」。和信度（Cronbach α）**挨着报**——
效度和信度本来就该一起看。

**三道关，按顺序过**：

1. **这份数据适不适合做因子分析** —— 两个指标，**读法相反**：

   | 指标 | 好的方向 | 说明 |
   |---|---|---|
   | **Bartlett 球形检验** | **p 要小** | H0 = "各题之间没有相关"。p 大 = 题目之间本来就没共同变异，做因子分析没意义 |
   | **KMO** | **越大越好** | <0.5 不可接受、>0.8 好、>0.9 很好 |

   ⚠ **"完全没共同变异"时 KMO ≈ 0.5，不是 0**：相关矩阵接近单位阵时，
   它的逆也接近单位阵 → 偏相关 ≈ 原相关 → 两个平方和相等 → KMO ≈ 0.5。
   （实测 n=400、6 题、200 次抽样：均值 0.496、范围 [0.437, 0.557]。）
   **所以"这份数据不行"的信号是「KMO 贴着 0.5 + Bartlett 不显著」，不是"KMO 接近 0"。**

2. **抽几个因子** —— 给两个依据，**按平行分析来**：

   | 依据 | 特点 |
   |---|---|
   | Kaiser 准则（特征值 >1） | 简单，但**题目多的时候会高估** |
   | **平行分析** | 跟随机数据比，实际特征值超过基准线的才保留——**更推荐** |

   碎石图看"拐点"也行，但那是主观的，所以才给平行分析这种有明确判据的。

3. **看旋转后的载荷** —— 每道题归到**最大载荷**的那个因子，一般要求 ≥0.40。

**三条容易说错的话**：

- **"旋转后解释率提高了"是错的**：旋转**不改变**总解释方差，
  只把它在因子之间重新分配。正确说法是"旋转后结构更清楚了"。
- **主成分（PCA）和主轴因子（PA）不是一回事**：前者看"解释了多少方差"、
  后者看"共同的潜结构"，**载荷不一样**，报告里必须写清用的哪个。
- **因子叫什么名字是人的判断**，程序只列"哪几道题落在这个因子上"。

**两个要盯的问题**：

- **双重载荷**：一道题在两个因子上都 ≥0.40（且相差不大）→ 结构里最不清楚的地方，
  通常要删掉或改写措辞。
- **共同度 <0.30**：这题跟其它题几乎没有共同变异，留在量表里贡献很小。

### 缺失值：为什么要用多重插补（2026-09-26 加，在 ⑤ 预处理里）

**别拿均值填补当默认。** 它有三个后果，而且**都往"更好看"的方向偏**：

| 后果 | 为什么 | 危险在哪 |
|---|---|---|
| 方差被压小 | 填进去的值没有变异 | 标准误偏小 → p 偏乐观 |
| 相关被稀释 | 填进去的值和谁都不相关 | 真关系被削弱、甚至看不见 |
| 分布被削平 | 所有缺失都堆到均值上 | 极端值/偏态被掩盖 |

**实测（真相关 0.600、真 SD 1.000、缺 25%）**：

| 做法 | 相关 r | x 的 SD |
|---|---|---|
| 完整个案 | 0.632 | — |
| **均值填补** | **0.456**（稀释 24%） | **0.900**（压小 10%） |
| **多重插补** | **0.646** | 1.03~1.05 |

**多重插补（MICE）怎么工作**：填 m 套（默认 5）**带随机扰动**的完整数据，
每套各算一遍，再用 **Rubin 规则**合并 —— 这样既保住变异，
又把"填得不确定"算进标准误里（**合并后的总方差一定大于任何单套**）。

⚠ 三条必须写进报告的话：

1. **插补不等于有数据**：它靠"缺失和被观测到的变量有关"这个假定（MAR）。
   如果缺失跟**没观测到的**东西有关（MNAR，比如"越介意的人越不答"），插补也救不了。
2. **跳题不该插补**：那道题对那个人本来就不适用，插一个值等于**编造**。
   所以插补前要先排除结构跳题。
3. **一定要报"插了多少"**：填了 30% 的格子和填了 1% 的格子，可信程度完全不同。

### 加权分析（2026-09-26 加，在 ⑥ 里，填了"权重列"才做）

**什么时候需要**：样本里各类人**抽中概率不一样**（分层抽样、过度抽样、事后加权）。

加权会改变"谁在代表谁"，所以有三件事必须一起报：

1. **权重的来源** —— 抽样设计？事后校正？这个只有研究员知道，但不写清就没法解释
2. **有效样本量 n_eff** —— 加权后"实际相当于多少人"（**通常小于** n）
3. **设计效应 DEFF = n / n_eff** —— 标准误被放大多少倍。
   **DEFF=2 就是「等于把样本量砍了一半」**，这句话最好懂

**实测（真值 15.00）**：未加权 11.93（被"多抽了低分组"带歪）→ 加权 **14.87** ✓，
n_eff 480/750、DEFF 1.56、标准误放大 1.45 倍。

⚠ 两条容易错的：

- **加权方差不是把 (x−均值)² 乘权重就完事**，还要除以 Σw 的平方修正项
  （可靠性权重）；不修正的话样本量小时会低估方差。
- **标准误要按 n_eff 算，不是按 n** —— 否则等于假装"权重没让信息变少"。

⚠ 权重为 0 等于剔除那个人；**负权重没有意义**；单个权重占比过大（>5%）
说明结论可能被少数个案主导 —— 这三种都要在分析之前报出来。
