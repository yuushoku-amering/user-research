# 测试素材（`_fixtures/`）

这里是**回归测试用的固定素材**，不是研究材料。改动它们之前先看这个说明。

## 为什么放在工作台里，而不是从某个项目里拿

原来 `_chaintest.py` 是从 `projects/_走查_大学生恋爱研究/samples/` 拷素材的 ——
那个项目一次被删掉（研究员在试「删除 = 移进回收站」），**整套全链回归当场跑不起来**：

```
FileNotFoundError: ...projects\_走查_大学生恋爱研究\samples\访谈转写稿_小周.txt
```

⚠ 教训：**测试不能依赖别人的项目、也不能依赖临时目录** ——
它得能在任何一台机器上、任何项目状态下独立跑起来。

## 里面是什么

```
_fixtures/
├─ 访谈转写稿_小周.txt          全链回归（🔒 → ② → 填码 → ②b）的第 1 份转写稿
├─ 访谈转写稿_小林.txt          第 2 份。**两份才验得出"多场访谈拼在一起"那条路**
├─ research_brief.md            ① 要用它；② 会从它的变量表里取项目专有词
├─ 研究员口述需求.txt            ⓪ 的输入样例
├─ 分析样例\
│   └─ clean_data.csv           回退（rewind）回归：两个 0/1 变量，
│                               保证"正态性不满足"那个检查点一定会出现
├─ 访谈样例\                     ②b / ② 的单人份回归素材
│   ├─ 编码工作表_单人份.csv       一人份、已填好码（5 个主题）
│   └─ 脱敏_访谈转写稿.txt         已脱敏（说话人是 `[姓名1]` 这种占位名）
└─ 情景_游戏DAU\                 `_selftest.py` 那 11 条用例的输入
    ├─ data\sim_survey.csv       412 行合成问卷
    ├─ data\sim_daily.csv
    ├─ data\sim_churn_platform.csv
    └─ samples\情景_游戏DAU下滑_*
```

两份转写稿**故意带着真名和手机号** —— 这样 🔒 那一棒才验得动
（守卫会不会报警、替换对不对、段数会不会被吞）。

其余素材里出现的姓名、手机号、邮箱、公司名**全是编的**
（`zhangwei1999@example.com`、`13812345678`、`星海科技`…），
产品名「小鹰扫描」也是虚构的 —— 它们只为让测试有真实格式的靶子。

## 素材必须能独立跑：不许依赖工作台外面的目录

2026-09-27 清查了一遍：`_selftest.py`、`_codesum_test.py`、`_rewindtest.py`、
`_llmtest.py`、`_llmfilltest.py` 原来都写死了**工作台外面某个真实案例项目**的
绝对路径（`..\projects\小鹰扫描_付费转化研究`）。后果和上面那条一模一样，
只是换了个形式：别人 clone 下来一跑就红，而红的理由跟被测代码毫无关系。

现在一律改成：**能用的真实项目在就用，不在就用这里的素材临时拼一个。**

⚠ 拼的一定是**临时目录**，不能直接拿 `_fixtures\` 当项目跑 ——
好几条用例会写产物（②b 把 `编码汇总.md` 写在编码表旁边、⑤ 生成
`output/clean_data.csv`、② 重写编码工作表），落到素材目录会把仓库弄脏。

## 为什么是「拷贝」而不是直接引用回收站

最早的几个文件是从 `用户研究/.trash/_走查_大学生恋爱研究_20260925_112257/` 复制过来的。
**复制而不是引用**：回收站里那份迟早会被清理掉，测试不能指着它活。
原始项目本身**没有被改动**（还在回收站里，界面点「撤销」就能原样还原）。
